# tat — Tips And Todo · 产品设计

## 1. 要解决的问题

| 现状 | 痛点 | tat 的做法 |
| --- | --- | --- |
| 每日待办记在记事本 | 没有「完成」的概念，越记越乱 | 只有两个动作：**添加**、**完成** |
| 专业 todo 软件 | 项目、标签、提醒、优先级……太重 | 不做分组、不做提醒、不做同步 |
| 每天要看比赛、股市 | 要开好几个 App / 网页 | 一行一条的 **Tips**：今天的比赛、主要指数涨跌 |
| 常驻窗口占地方 | 挡住工作区 | **鼠标碰到屏幕最右侧自动滑出，移开自动收起**；需要时可以「钉住」常驻 |

一句话定位：**屏幕右边缘的一张便签——今天要做的事 + 今天值得瞄一眼的事。**

## 2. 设计原则

1. **零占用**：默认不在 Dock 出现、不显示窗口，只有一个菜单栏图标。
2. **两秒完成**：呼出 → 输入 → 回车，两秒内记下一条待办；点一下圆圈完成。
3. **只看一眼**：Tips 只给结论（时间、比分、涨跌幅），不给图表、不给新闻。
4. **不打扰**：悬停呼出时不抢键盘焦点；只有点进面板或用快捷键呼出时才接管输入。
5. **原生**：SwiftUI + AppKit，系统毛玻璃材质、SF Pro、SF Symbols，自动跟随深浅色。

### 3.1 Todo

- **添加**：输入框回车。新条目插入列表顶部，空白内容忽略，最长 200 字。
- **完成**：点击圆圈 → 勾选动画 → 移入「已完成」。再点一次可撤销。
- **删除**：悬停行尾 ×，或右键菜单「删除」（用于修正手误）。
- **跨天规则**：未完成的自动顺延到第二天；**前一天已完成的在新的一天自动清空**，让列表永远只有「今天」。
- 存储：`~/Library/Application Support/tat/todos.json`，每次修改原子写入。

### 3.2 Tips

| Tip | 数据源 | 默认 | 可选 |
| --- | --- | --- | --- |
| 市场指数 | 腾讯行情 `qt.gtimg.cn`（免 key，国内可直连） | 上证指数、深证成指、创业板指、恒生指数、纳斯达克100、标普500、道琼斯 | 沪深300、科创50、恒生科技、国企指数、纳斯达克综指 |
| 今日赛事 | ESPN 公共 scoreboard 接口（免 key） | 英超 | 西甲、意甲、德甲、法甲、欧冠、中超、NBA |

- 「今天」的赛事窗口 = 本地 **今日 00:00 → 次日 06:00**，覆盖国内看球习惯里的「今晚 + 凌晨」；凌晨场次标注「次日」。
- 球队名优先显示中文常用译名，未收录的显示英文简称。
- 刷新策略：面板可见时，数据超过 3 分钟就刷新；面板收起时不发任何请求（省电）。手动 ↻ 随时刷新。
- 失败时在对应区块内显示「加载失败 · 重试」，不影响其他区块和 Todo。

### 3.3 赛事提醒

| 场景 | 行为 |
| --- | --- |
| 未开赛的比赛 | 行尾显示铃铛（空心、淡色，悬停加深）；进行中 / 完场的比赛不显示，但保留位置让列对齐 |
| 点铃铛 | 变为实心强调色并轻弹一下；在「开球时间 − 提前量」弹出系统通知 |
| 再点一次 | 取消提醒 |
| 提前量 | 设置 → 赛事 →「比赛提醒」：开赛时 / 提前 5 / 15（默认）/ 30 分钟 / 1 小时；修改后所有已设提醒立即按新提前量重排 |
| 设提醒时已不足提前量 | 立即提醒，文案写实际剩余时间（如「5 分钟后开赛」） |
| 开球时间变更（延期） | 刷新赛程时自动跟随新时间重排；比赛开始后提醒自动清除 |
| 第一次点铃铛 | 请求系统通知权限；铃铛先亮起，不等弹窗 |
| 通知权限被关闭 | 铃铛仍保留，赛事区和设置里提示「系统通知已关闭 · 去开启」；在系统设置里打开后，下次打开面板自动补排 |
| 点击通知 | 打开面板 |

- 通知文案：标题「英超 · 15 分钟后开赛」，正文「切尔西 vs 曼联 · 20:30 开球」。
- 通知交给系统调度，**tat 没在运行也会准时弹出**。
- 存储：`~/Library/Application Support/tat/reminders.json`（含对阵与开球时间，比赛不在今日列表里也能正确提醒）。

## 4. 交互：边缘呼出

| 场景 | 行为 |
| --- | --- |
| 鼠标贴到屏幕最右侧并停留 ≥ 触发延迟（默认 150ms） | 面板从右侧滑入（200ms ease-out） |
| 鼠标离开面板（含 16pt 容差）超过 400ms | 面板滑出收起 |
| 输入框里有未提交的文字 | 不自动收起，避免丢字 |
| 按住鼠标拖拽中经过右边缘 | 不触发（避免干扰拖窗口、拖文件） |
| 右上角菜单栏区域 / 右下角 6pt | 不触发（避开控制中心与触发角） |
| 多显示器 | 只在「外侧」的右边缘触发；两块屏相接的那条边不触发 |
| 钉住 📌 | 面板常驻显示，不再自动收起 |
| ⌥⌘T | 在鼠标所在屏幕呼出/收起并聚焦输入框；鼠标进入过面板后才开始「移开收起」 |
| Esc | 收起（未钉住时） |
| 系统开启「减弱动态效果」 | 只做淡入淡出，不做位移 |

面板：宽 320pt，最高 680pt（内容更多时滚动），贴在屏幕右上角、距菜单栏和右边缘 8pt（与通知中心位置一致），圆角 14pt，系统毛玻璃（popover material），浮于普通窗口之上，可出现在所有桌面空间和全屏 App 上。

## 5. 视觉规范

- **字体**：SF Pro（系统字体）。日期 15pt semibold；正文 13pt；区块标题 11pt semibold 次级色；数字使用等宽数字（monospacedDigit）。
- **颜色**：强调色 Teal `#0D9488`（深色模式 `#2DD4BF`）；涨 `#E5484D` / 跌 `#30A46C`（可切换为绿涨红跌）；其余全部使用系统语义色（label / secondaryLabel / separator），保证深浅色对比度 ≥ 4.5:1。
- **图标**：只用 SF Symbols，不用 emoji。
- **间距**：4pt 网格；面板内边距 14pt；行高 ≥ 28pt，点击区域整行可点。
- **动效**：只给三处动效——面板进出、完成勾选、铃铛设置时轻弹；150–250ms；尊重「减弱动态效果」。

## 6. 设置（面板内齿轮进入）

- 行为：常驻显示、触发延迟（立即 / 150ms / 400ms）、开机自动启动
- 市场：勾选要看的指数
- 赛事：勾选要看的联赛；比赛提醒提前量（开赛时 / 5 / 15 / 30 分钟 / 1 小时）
- 涨跌颜色：红涨绿跌 / 绿涨红跌
- 底部：版本号、快捷键提示、退出

菜单栏图标菜单：显示/隐藏面板、常驻显示、开机自动启动、退出；图标旁显示未完成待办数。

## 7. 明确不做

多列表 / 标签 / 优先级 / 截止日期 / 提醒推送 / 云同步 / 账号体系 / 自选股 / K 线图 / 新闻。

## 8. 技术方案

- Swift 6 + SwiftUI（界面）+ AppKit（`NSPanel`、`NSStatusItem`、全局鼠标监听、Carbon 全局快捷键）
- `LSUIElement`：无 Dock 图标；最低 macOS 14
- `EdgeTrigger`：纯逻辑状态机（输入：鼠标位置、时间、屏幕布局、面板状态 → 输出：显示/隐藏/等待），单元测试全覆盖
- 数据层 `TodoStore` / `TipsStore` 通过协议注入数据源，UI 测试使用固定桩数据
- 工程由 XcodeGen（`project.yml`）生成
- 测试：XCTest 单元测试 + XCUITest 端到端测试（真实启动 App，模拟鼠标移到右边缘、添加/完成待办、设置切换）
- CI：GitHub Actions 每次 push / PR 跑构建 + 全部测试；推送 `v*` tag 自动构建并发布 Release（`.zip` + `.dmg`）
